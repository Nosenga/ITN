[p40] Chapter 2 Summary :: Cisco IOS: The technician can enter commands to configure, or program, the device to perform various networking functions. Services are generally accessed using a command-line interface (CLI), which is accessed by either the console port, the AUX port, or through telnet or SSH. Once connected to the CLI, network technicians can make configuration changes to Cisco IOS devices. Cisco IOS is designed as a modal operating system, which means a network technician must navigate through various hierarchical modes of the IOS.
