1Chapter overviewFrom the course PDFs

Chapter 9 is the subnetting workshop: why large networks are divided (broadcast control, traffic reduction, performance), what to plan first (number of subnets, number of host addresses), and the core formula — 2n usable hosts where n = remaining host bits, minus 2 for the subnetwork ID and broadcast address. It then shows how traditional fixed-size subnetting wastes addresses (WAN links need only two) and how VLSM divides the network into unequal parts (LANs get /27s, WAN links /30s in the worked example). Section 9.2 covers planning and documenting address allocation (no duplication, access control, monitoring; clients usually via DHCP), and 9.3 flags IPv6 design considerations.

Learning objectives

  • Explain why large networks are segmented into subnets and what a router/interface must have for subnets to communicate (slide 4).
  • Plan a subnet from two inputs — subnets required and host addresses required — and apply the 2n − 2 formula (slides 5–7).
  • Explain how traditional subnetting wastes addresses and how VLSM solves it (slides 8–10).
  • State the purposes of a documented network addressing plan and the role of DHCP for client addresses (slide 12).
  • Recognise the IPv6 design considerations raised for larger networks (slide 13).

Most important concepts

  • Segmentation — containing broadcast traffic, reducing overall traffic, improving performance.
  • Subnet plan — subnets required + host addresses required drive everything.
  • Usable hosts = 2n − 2 — subnetwork ID and broadcast are never assignable.
  • Traditional vs variable-length — equal allocations waste space; VLSM sizes each subnet to need.
  • Address planning — documented allocation prevents duplication and supports access control/monitoring.
  • Default gateways — each subnet's router interface is the exit for its hosts.

2Key definitionsFrom the course PDFs

Subnet (subnetwork)

A smaller network space created by segmenting a large network into smaller groups of devices and services. slide 4

Reasons for subnetting

Control traffic by containing broadcast traffic within each subnetwork, and reduce overall network traffic to improve performance. slide 4

Default gateway (in subnets)

The router interface attached to a LAN; devices on that network/subnet use it to reach other networks. Each router interface needs an IPv4 host address belonging to the network/subnet it is connected to. slide 4

Subnetting plan inputs

The two questions to answer first: number of subnets required and number of host addresses required. slide 6

Host-bits formula

2n gives the number of addresses where n = the number of remaining host bits; subtract 2 because the subnetwork ID and broadcast address cannot be used on each subnet. slide 6

Traditional subnetting

Allocating the same number of addresses to every subnet — subnets that need fewer end up with unused (wasted) addresses; WAN links only need two. slide 8

VLSMVariable Length Subnet Mask

Also called 'subnetting a subnet' — divides a network space into unequal parts; the mask varies with how many bits are borrowed for each subnet; the network is first subnetted, then subnets are resubnetted — more efficient use of addresses. slide 9

Addressing plan

A planned, documented allocation of network addresses — done to prevent duplication of addresses, provide and control access, and monitor security and performance. slide 12

DHCP-assigned client addresses

Client addresses are usually dynamically assigned using DHCP (mechanism detailed in Chapter 10). slide 12

3Concept explanationsStudy note

Why the router and its interface address matter slide 4

Devices on different networks/subnets can only communicate through a router. Every router interface must carry an IPv4 host address in the subnet it connects to — that address is the default gateway for the hosts on that LAN. Subnetting without a gateway traps hosts inside their own broadcast domain.

Example: Hosts on 192.168.10.0/24 use R1's G0/0 address as their gateway; R1's G0/0 must hold a valid .x host address of that same subnet.

Using the formula end to end slide 7

Start from the plan questions: how many subnets? how many hosts per subnet? For hosts: count remaining host bits n → 2n total addresses → −2 usable (subnetwork ID and broadcast are reserved). Design to the largest subnet's maximum host count, balance subnets vs hosts there, and allow growth in each subnet.

Example: 30 hosts need 25 = 32 addresses → 30 usable → exactly /27-sized blocks (matches the VLSM example's LAN allocation).

Where traditional subnetting goes wrong slide 8

Fixed allocation gives every subnet the same block. Big subnets get what they need; small ones don't — and WAN links, which need only two addresses, still receive whole equal-sized blocks. The leftovers are simply wasted.

Example: Ten WAN links each handed a /24 would burn 2,540 addresses for traffic that needs 20.

How VLSM fixes the waste slide 10

VLSM lets mask length vary per subnet according to borrowed bits: size large LANs bigger, tiny WAN links smaller — 'subnetting a subnet'. The worked example: each LAN gets a /27, each WAN link a /30, so LAN and WAN segments are addressed with minimum waste.

Example: /30 = 4 addresses = exactly network, two endpoints, broadcast — no waste on a point-to-point link.

Why document the addressing plan slide 12

Documented allocation exists to prevent duplicate addresses, to provide and control access, and to monitor security and performance. Client addresses are usually left to DHCP dynamically, while the plan still defines the pools.

Example: A static address outside the documented plan breaks access control lists and makes incidents harder to trace.

6Knowledge checkPractice

7 practice questions — a mix of multiple-choice, true/false, short-answer and explanation tasks. Answers stay hidden until you reveal them, and each one explains why it is correct. These are revision questions written for this site from the course content — they are not lecturer instructions or examination questions.

Multiple choiceQ1. Which two goals are given for segmenting a large network into subnets?

  • A. Contain broadcast traffic and reduce overall traffic / improve performance
  • B. Increase broadcast traffic and add more addresses
  • C. Eliminate the need for routers
  • D. Assign the same address to every device
Show answer & explanation

Answer: A — Contain broadcasts, reduce traffic, improve performance

Why: Slide 4: create smaller groups 'to control traffic by containing broadcast traffic within each subnetwork' and 'reduce overall network traffic and improve network performance'.

Short answerQ2. Write the usable-host formula from the chapter and explain both parts.

Show answer & explanation

Answer: Usable hosts = 2n − 2, where n is the number of remaining host bits. 2n counts all addresses in the block; 2 is subtracted because the subnetwork ID and the broadcast address cannot be assigned to hosts.

Why: Slide 6 gives the formula and the reason for the minus 2 verbatim.

True or falseQ3. In traditional subnetting, every subnet receives the same number of addresses, so a WAN link that needs only two addresses may waste the rest of its block.

Show answer & explanation

Answer: True

Why: Slide 8: traditional subnetting 'uses the same number of addresses' for each subnet; 'WAN links only need two addresses', leaving unused (wasted) addresses.

Multiple choiceQ4. In the VLSM example, what mask sizes are assigned?

  • A. /27 for LANs and /30 for WAN links
  • B. /24 for LANs and /24 for WANs
  • C. /30 for LANs and /27 for WANs
  • D. /28 for every link
Show answer & explanation

Answer: A — /27 for LANs, /30 for WAN links

Why: Slide 10: 'Each LAN will be assigned a subnet with /27 mask. Each WAN link will be assigned a subnet with /30 mask.'

Short answerQ5. What two numbers must your subnetting plan establish first?

Show answer & explanation

Answer: The number of subnets required, and the number of host addresses required.

Why: Slide 6 'Subnetting Based on Host Requirements' lists exactly these two.

ExplanationQ6. Why must each router interface hold an IPv4 host address belonging to the subnet it connects to, and what do hosts on that subnet use it for?

Show answer & explanation

Answer: Devices on different networks/subnets can only communicate via a router. An interface's address must belong to its own subnet so it can act as an endpoint there; hosts on that LAN use the interface's address as their default gateway to leave the subnet.

Why: Slide 4 states both requirements — interface host address in the connected subnet, and devices using that interface as default gateway.

Short answerQ7. Give three reasons for planning and documenting network address allocation.

Show answer & explanation

Answer: Preventing duplication of addresses; providing and controlling access; monitoring security and performance.

Why: Slide 12 lists these three purposes.

7Common misunderstandingsStudy note

Usable hosts = 2<sup>n</sup>

Every subnet also has a subnetwork ID and a broadcast address — both unassignable — so usable = 2n − 2 (slide 6).

WAN links need 'a real subnet' like LANs

A point-to-point WAN needs only two addresses; giving it an equal-sized block is exactly the waste traditional subnetting creates (slide 8) — VLSM's /30 fixes it (slide 10).

VLSM is just subnetting twice

It is planned unequal division: the mask varies with borrowed bits per subnet, first subnetting then resubnetting, to minimise waste (slide 9).

Subnetting is only about security

The chapter's stated first goals are containing broadcast traffic and reducing traffic for performance (slide 4); security/access control comes via the addressing plan (slide 12).

8Quick revision (2–5 minutes)Study note

  • Why subnet: contain broadcasts per subnetwork; cut overall traffic; improve performance. Routers connect subnets; each router interface = a host address in its subnet = the LAN's default gateway.
  • Plan: how many subnets? how many hosts? Design for the largest subnet's max hosts and allow growth.
  • Formula: 2n − 2 usable hosts (n = remaining host bits; −2 = subnetwork ID + broadcast are reserved).
  • Traditional wastes: equal blocks for everyone; WAN links need only two addresses.
  • VLSM: unequal parts, mask varies with borrowed bits, subnet-then-resubnet; example: LANs /27, WANs /30 → minimum waste.
  • Plan document: prevents duplicate addresses, enables access control, supports security/performance monitoring; clients usually get addresses via DHCP.

Network Segmentation

Reasons for Subnetting

Subnetting is the process of segmenting a network into multiple

smaller network spaces called subnetworks or subnets.

  • Large networks must be segmented into smaller subnetworks, creating smaller groups of devices and services to:
  • Control traffic by containing broadcast traffic within each subnetwork.
  • Reduce overall network traffic and improve network performance.

Communication Between Subnets

  • A router is necessary for devices on different networks and subnets to communicate.
  • Each router interface must have an IPv4 host address that belongs to the network or subnet that the router interface is connected.
  • Devices on a network and subnet use the router interface attached to their LAN as their default gateway.

  • VLSM allows a network space to be divided in unequal parts.
